2. Bug Reports & Technical Support

If you encounter a PDF layout anomaly, font rendering edge case, Excel table parsing bug, or browser file-saving issue, please open an issue on GitHub so it can be investigated and tracked:

  • Open a Bug Report: GitHub Issues — PDFGod
  • Helpful Details to Include: Your browser name/version (e.g., Google Chrome, Safari, Edge), operating system, steps to reproduce, and whether the issue occurs with specific embedded fonts or encrypted PDFs. (Never attach confidential personal PDFs to public bug reports.)

3. Feature Requests & Community Feedback

Have an idea for a new PDF tool, shortcut, export format, or typography improvement? Share requests directly with the developer and community:
