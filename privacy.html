Privacy Policy & Cookie Disclosure

Effective Date: October 15, 2026 • Last Updated: November 13, 2026

1. 100% Local Document Processing Guarantee

PDFGod (hosted at https://chayneps.github.io/ and https://chayneps.github.io/pdfgod/) is engineered as a purely client-side web application. When you open, view, edit, sign, redact, encrypt, or export a PDF or Excel file in PDFGod:

  • Zero Server Uploads: Your files, text contents, passwords, images, and signatures are never uploaded, transmitted, or copied to any external server.
  • In-Memory Execution: All PDF parsing, rendering, font embedding, and binary serialization execute strictly inside your web browser's local memory sandbox on your personal device.
  • File System Access API: When you grant permission to open or overwrite a local file via your browser's native file picker, access is mediated directly by your operating system and web browser strictly for the file you explicitly select.

2. Local Browser Storage (localStorage)

To improve your editing workflow across sessions, PDFGod uses your browser's standard window.localStorage API to store preferences locally on your computer, including:

  • Preferred multi-column page grid layout setting (pdfgod_layout_columns).
  • Saved signature slots (drawn paths and typed cursive presets) that you choose to save for reuse.
  • Saved annotation layer templates and batch-editing text snippets.

This data remains strictly inside your local browser profile and is never transmitted over the network. You can clear this data at any time inside the application or by clearing your browser's site data.
