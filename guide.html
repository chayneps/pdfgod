1. In-Place PDF Text Editing & Precision Alignment

One of the most common frustrations with standard PDF viewers is that existing text is locked inside static content streams. PDFGod solves this by extracting the underlying PDF text matrix—including exact X/Y coordinates, font family, point size, and character spacing—and converting clicked text spans into live, editable vector fields.

Step-by-Step Workflow

  1. Activate the Select Text Tool: Click the Select text button in the top toolbar or press E on your keyboard.
  2. Click Any Existing Text Line: Hover over any paragraph, invoice number, or heading in your PDF. Clicking a text line automatically places a clean cover mask over the original PDF glyph run and overlays an interactive text box matching the original typography.
  3. Two-Stage Selection Model:
    • First Click (Box-Selection Mode): Selects the bounding box (indicated by a dashed blue outline). In this mode, you can drag the element anywhere on the page or use the Arrow Keys to nudge the position by 5px (or Shift + Arrow Keys for 1px micro-nudges).
    • Second Click (Character-Editing Mode): Places the blinking text caret inside the text box (indicated by a solid blue outline) so you can type, delete, or paste text naturally.
  4. Center on Page & Multi-Select Alignment: Hold Shift and click multiple text elements (or drag a marquee selection box around them) to align them along their left, center, or right edges, or click Center on Page to mathematically center a heading across the full page width.
Pro Tip: When PDFGod exports your document, edited text is embedded as genuine vector PDF font operators—not blurry rasterized screenshots—ensuring your text remains crisp at any zoom level and fully searchable.

2. Multi-Page Batch Header, Footer & Disclaimer Editing

When working with 50-page contracts, financial reports, or manuals, manually updating a recurring header, date, or revision number on every single page is tedious and error-prone. PDFGod includes a specialized Multi-Page Batch Group Editor with a real-time Visual Layout Preview.

How to Batch-Edit Recurring Text Across All Pages

  1. Select one or more text lines or vector divider lines on any page using the Select (V) or Select text (E) tool.
  2. Click Match Across Pages in the floating Batch Bar. PDFGod scans the spatial coordinates and text patterns across every page in the document and highlights all matching occurrences.
  3. Open the Visual Layout Preview modal to edit all matched pages simultaneously:
    • Modify text content, font family, font size, bolding, and color for each line in the group.
    • Adjust vertical line spacing and horizontal alignment visually before applying changes.
    • Save recurring header/footer blocks as Saved Snippets or Saved Layers in your browser's local storage so you can stamp them onto future PDF documents with one click.

3. Multi-Slot Digital Signatures, Cursive Scripts & Transparent Stamps

Signing contracts, tax forms, and authorization letters requires clean, high-resolution signatures that preserve transparency over signature lines.

Three Ways to Create Signatures in PDFGod

  • Freehand Draw Mode (3 Saved Slots): Draw your signature smoothly using a mouse, trackpad, or stylus. PDFGod applies quadratic Bézier curve smoothing and lets you customize both ink color (black, navy blue, crimson) and stroke thickness. Up to 3 drawn signatures are automatically persisted in slots for instant reuse.
  • Typed Cursive Signature Mode (3 Saved Slots + 4 Script Styles): Type your name and switch between four calligraphic script fonts (Great Vibes, Dancing Script, Sacramento, and Alex Brush). Each slot remembers your text, chosen script font, and ink color.
  • Image / Company Seal Upload: Upload a PNG or JPEG image of your handwritten signature or official company stamp. Corner resize handles automatically lock aspect ratio so your signature never stretches or distorts.

4. True Stream Redaction vs. Whiteout & Vector Annotations

Protecting personally identifiable information (PII), account numbers, and medical records requires understanding the difference between visual masking and stream-level removal.

  • Whiteout (R) & Blackout Tools: Draw opaque rectangular blocks over regions of a page to visually obscure old stamps, logos, or form fields before placing new text on top.
  • Stream-Level Text Redaction: When you edit or delete existing PDF text via the Select text tool or Batch Editor, PDFGod rewrites the underlying PDF content stream operators (BT ... ET) to strip the original text strings so hidden text cannot be copied or extracted from the exported file.
  • Shapes, Arrows & Checkmarks: Use the toolbar to insert vector rectangles, circles, straight lines, directional arrows, green checkmarks (✓), and red cross marks (✗) for form completion.

5. Converting Multi-Page PDF Tables to Excel (.xlsx)

Financial statements, invoices, and bank statements are frequently distributed as locked PDFs. PDFGod includes a built-in, zero-server Excel Workbook Exporter that reconstructs tabular layouts into native OpenXML (.xlsx) spreadsheets.

How the PDF-to-Excel Engine Works

  1. Open your PDF containing tables or financial schedules. (Any in-place text edits or whiteouts you make in the editor are respected during export!)
  2. Click the dropdown arrow next to the Save button and select Export to Excel (.xlsx).
  3. PDFGod analyzes horizontal and vertical vector paths alongside text baseline coordinates across every page, clustering rows and columns into structured spreadsheet cells while preserving font weights, numeric alignments, and cell borders.

6. Authentic Thai Language Support (ภาษาไทย), Sarabun Fonts & พ.ศ. Dates

Standard PDF libraries frequently break Thai text due to three-level vertical glyph stacking (consonants, upper/lower vowels, and tone marks) and legacy Windows-874 Private Use Area (PUA) encodings. PDFGod v18 features a dedicated Thai typography engine:

  • Bundled Sarabun TrueType Fonts: Authentic Google Fonts Sarabun Regular and Sarabun Bold are embedded directly inside the application for 100% offline vector rendering.
  • Zero Vertical Clipping: Automatic line-height expansion (1.45) ensures upper tone marks (ไม้เอก, ไม้โท, ไม้ตรี, ไม้จัตวา) and lower vowels (อุ, อู) are never clipped during editing or export.
  • Legacy PUA & Sara Am Normalization: Automatically converts legacy PUA codepoints (\uF700–\uF71A) and decomposed Sara Am sequences into standard Unicode so exported Thai PDFs can be searched and copy-pasted accurately.
  • One-Click Buddhist Era Date Stamper (📅 พ.ศ.): Insert today's official Thai Buddhist Era date (e.g., 13 พฤศจิกายน 2569) directly from the text properties bar.

7. Client-Side AES-256 Password Protection & Unlocking

Need to password-protect a sensitive PDF before emailing it, or remove a password from a PDF you already own?

  • Opening Encrypted PDFs: When you open a password-protected PDF, PDFGod prompts for the document password and unlocks the permissions in memory.
  • Adding or Changing a Password: Click the Lock Icon in the top header (or use Save As...) to set, update, or remove a password. PDFGod encrypts the exported binary using 256-bit AES encryption entirely inside your browser.

8. Direct In-Place File Overwriting & Multi-Page Organization

Starting in PDFGod v18, the editor integrates the modern W3C File System Access API on Chromium browsers (Google Chrome, Microsoft Edge, Brave, Opera):

  • Overwrite Existing Files Without Duplicate Numbers: When you open a PDF via Choose PDF File or drag-and-drop, PDFGod retains the active file handle. Clicking Save (Ctrl+S) and confirming "Yes, Replace" writes directly back to your original file on disk instead of creating document (1).pdf, document (2).pdf copies in your Downloads folder.
  • Multi-Column Page Sorter (1, 2, or 3 Columns): Switch the main viewport between 1-column, 2-column, and 3-column grid views to drag-and-drop page ranges, rotate pages, insert blank pages, merge multiple PDF files, or extract selected pages into a separate PDF file.
