Release Notes & Engineering Changelog

Continuous curation, architectural improvements, and feature releases across 18 versions of PDFGod.

PDFGod v18 — File System Access API & Direct In-Place Overwrite Latest Release
  • In-Place File Overwriting: Integrated W3C FileSystemFileHandle.createWritable() so clicking Save and confirming "Yes, Replace" directly overwrites the opened PDF file on disk instead of generating duplicate numbered files (e.g., document (1).pdf) in the browser Downloads folder.
  • Active File Handle Retention: Captures and persists the active FileSystemFileHandle both when opening files via window.showOpenFilePicker and when dragging and dropping files via DataTransferItem.getAsFileSystemHandle().
  • Native Save As Picker & Shortcut: Integrated window.showSaveFilePicker into Save As... and Extract Selected Pages flows, and added the Ctrl+Shift+S / Cmd+Shift+S keyboard shortcut.
PDFGod v17 — Multi-Slot Signatures, Cursive Scripts & Proportional Resizing
  • 3-Slot Drawn & Typed Signatures: Added persistent LocalStorage slots for up to 3 drawn freehand signatures and 3 typed cursive signatures, allowing instant switching between full signatures and initials.
  • Calligraphic Script Selector: Added 4 cursive signature fonts (Great Vibes, Dancing Script, Sacramento, and Alex Brush) with customizable ink colors.
  • Proportional Aspect-Ratio Locking: Corner resize handles on signatures and uploaded images now preserve exact aspect ratios to prevent distortion.
PDFGod v16 — Dedicated Direct Multi-Page Print Engine
  • High-Resolution Print Pipeline: Added a dedicated Print button in the header and Ctrl+P / Cmd+P shortcut that renders all PDF pages and vector annotations into an isolated high-DPI print container without printing UI toolbars or sidebars.
PDFGod v15 — Client-Side AES-256 Encryption & Password Management
  • 256-Bit AES Encryption: Added full client-side PDF encryption and password protection via pdf-lib-encrypt.
  • Password Unlock & Permission Bypass: Supports opening password-protected PDFs, viewing security status in the header lock badge, and changing or removing passwords during export.
PDFGod v14 & v13 — Saved Layer Templates & Retina Thumbnail Sync
  • Saved Layers in LocalStorage: Save complex multi-element annotation layers (stamps, form overlays, headers) with live hover previews and one-click insertion onto any page.
  • Retina Thumbnail Synchronization: Sidebar page thumbnails dynamically re-render in real time as annotations and text edits are applied on the main canvas.
PDFGod v12 & v11 — Multi-Page Extraction & Text Baseline Collision Fixes
  • Extract Pages to New PDF: Select any combination or range of pages in the main viewport and export them as a standalone PDF or cut-and-extract them in one operation.
  • Sub-Pixel Text Rise & Collision Resolution: Fixed vertical baseline drift on complex multi-column PDFs and relocated status notifications to the bottom-left viewport corner.
PDFGod v10 — Full Thai Language Support (ภาษาไทย) & Bundled Sarabun Fonts
  • Embedded Sarabun TrueType Fonts: Bundled authentic Sarabun Regular and Sarabun Bold TrueType binaries via @pdf-lib/fontkit for 100% offline Thai PDF editing.
  • PUA Normalization & Custom CMap Patching: Added automatic conversion for legacy Windows-874 Private Use Area glyphs, unclipped 1.45 line-height for stacked Thai tone marks, Intl.Segmenter word selection, and a Buddhist Era (พ.ศ.) date stamper.
PDFGod v9, v8 & v7 — Marquee Multi-Selection, Spatial Grid & Page Rotation Sync
  • Synchronized Annotation Rotation (v9): Rotating a PDF page automatically transforms and rotates all overlaid text boxes, drawings, and vector shapes in 90° increments.
  • Marquee Multi-Selection & Spatial Grid (v8): Drag a selection rectangle across any page to select and batch-redact multiple text spans and vector lines simultaneously.
  • Arrow Key Nudging & Clipboard Support (v7): Added 5px and 1px arrow-key nudging, Ctrl+C/Ctrl+V copy-paste, and vector line group selection.
PDFGod v6 through v1 — Core Vector Engine, Batch Group Editor & Excel Exporter
  • v6 — Multi-Page Batch Group Editor: Introduced Match Across Pages and the interactive Visual Layout Preview stage for updating headers and footers across entire documents.
  • v5 & v4 — Client-Side PDF-to-Excel (.xlsx) Exporter: Built a zero-dependency OpenXML ZIP workbook generator that converts multi-page PDF tables and vector borders into editable Excel spreadsheets.
  • v3 & v2 — Multi-Column Grid Layout & Drag-and-Drop Page Sorter: Added 1-, 2-, and 3-column page viewing modes and drag-and-drop page reordering/merging.
  • v1 — Initial Release: Single-file client-side PDF viewer and editor combining PDF.js and PDF-Lib with zero server uploads.
